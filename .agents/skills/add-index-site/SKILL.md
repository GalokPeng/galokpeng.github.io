# 把站点加到首页

1. 从仓库根目录打开 `index.html` 的 `#sites .sites-grid`，按目标地址查找已有卡片。已有站点可原位更新，保留排序与书签。站内入口沿用 `/world/` 这样的根路径；外站保留完整的最终 HTTP(S) 地址以及有实际用途的查询参数或片段。
2. 打开目标页面核实名称和用途。为新卡写能说明「进去可以做什么」的一句话，中英文分别填写。品牌名可以共用；需要翻译的 `h3` 和简介使用 `data-en`。使用页面自己的公开预览或用户提供的截图；需要登录的页面可用公开落地页或获准展示的图片。
3. 从实际页面截取有辨识度的区域，裁成 WebP，放到 `home/previews/<slug>.webp`。在相邻卡片旁复制 `a.site-card`，替换链接、图片尺寸、标题与简介。普通卡目前用 560 × 295 和懒加载，指定为大卡时参考已有 `featured` 卡的 900 × 420。首页加载预览图片，用户点击才进入目标网站。
4. 在仓库根目录运行下面的检查（Python、Beautiful Soup 和 Pillow）。用刚添加的实际地址替换参数。它同时核对卡片唯一性、双语简介、预览格式和声明尺寸。

```sh
python .agents/skills/add-index-site/scripts/check_site.py "/world/"
```

用 Jekyll 构建后从 `/#sites` 看手机和桌面效果，在 `/?lang=en` 核对英文，用键盘进入卡片并验证实际落地页。若用户要求发布，推送后再从正式首页点一次。
