## 分发校验

压缩包附外置 SHA-256；包内 CONTENTS.sha256 列出静态文件摘要（不包含自身）。打包排除 Python 字节码与测试缓存。接收后可先核对下载摘要，再解压并在此目录运行 `python -m unittest discover -s tests -v`。重新运行会产生本地缓存，它们不属于发布内容。
