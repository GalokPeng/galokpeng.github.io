# 本包验证记录

2026-11-23 在 Windows x64、Python 3.11.9 上验证。工具的兼容目标为 Python 3.10+，本次实测的解释器为 3.11.9。

## 可复验的结果

- 源目录和独立临时目录中的解压副本均通过 skill-creator 格式校验与 35 项自动化测试。包内相对文档链接、UI 元数据、文件清单和 SHA-256 均经核对。
- 原有 26 项检查覆盖多仓库候选、门禁来源、制品完整性、路径处理和只读 HTTP 校验。网络夹具在本机测试完整下载、跳转、摘要、慢速响应和错误页。
- 新增 9 项 MSIX 测试覆盖包身份、显示名、架构、四段版本、受限能力、PRI 待核验、外层 ZIP 摘要、同一 manifest 下的负载变化及 CLI 退出码。单独从可信发行清单取得摘要，并对一份已发布的真实 MSIX 做过离线复核。

## 场景演练

一名独立评估者按技能处理了“Actions 有商店 ZIP、Release 缺附件、维护者自行上传，同时有另一个同名文件”的桌面演练。合成夹具揭示了历史安装版本末段可能由 Store 改为非零的情况。修正后，工具接受较低的已安装版本，且会拒绝不能升级它的同版或低版候选。更多演练见 [14 个场景](scenarios.md)。

本次验证使用本地数据与只读官方资料。实际安装升级、签名信任、远端发布和商店认证各有独立的验收步骤。复用本技能时按目标渠道收集对应证据。

## 收包核验

外部 SHA-256 对应整个 ZIP。包内 `CONTENTS.sha256` 列出除自身外每个交付文件的摘要。解压后进入 `ship-software-product`，可用 `python -B -m unittest discover -s tests -v` 运行自测。
