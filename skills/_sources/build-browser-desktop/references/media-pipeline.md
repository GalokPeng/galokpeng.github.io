# 媒体、截图和录屏

根据实际功能阅读对应一节。先确定输出范围是画板像素、应用窗口还是整个体验桌面，并把范围写在操作按钮与验收中。

## 预览图库与下载

给每个素材保存稳定 ID、类型、标题、宽高、字节数、封面、可播放预览、原文件地址、作者与许可。能获取受信任摘要时将其纳入清单。构建时可以用 Pillow、FFmpeg 等生成小封面与短片。浏览器难以解码的源格式可额外提供适配的预览。保留原件的来源，并标明预览时长、静音与缩放等实际改变。跨域图片在 img 中能显示，并不代表可以直接读取像素；提前验证 CORS 或使用经许可的同源预览。

选择条目 → 开始预览 → 停止预览 → 下载原件 → 应用，是可以分别验收的动作。img.decode() 或视频 loadeddata / error 反馈准备结果，视频预览可用 muted、playsInline 和 controls。切换时暂停旧视频、释放媒体源，按需取消正在进行的请求。原件下载从连接阶段就显示状态；有可信总字节数再显示百分比，长度未知就显示已接收字节。网络错误可以重试，实际校验成功后才写“已下载”。

同一播放器连续选择两项时，使用递增序号与 AbortController。第一项结束后的 catch、finally、播放器回调均需检查是否仍是当前项。旧任务不能覆盖新项状态。对象 URL 在替换或关闭时回收，设置缓存的字节预算。窗口重绘不会自动替你暂停旧解码器。长列表使用小封面和惰性加载。

## 冻结底图、选区、笔迹

- **获取底图。** 已用 Canvas 绘制的应用可直接复制当前渲染结果。DOM 桌面可按同一场景模型绘制，或用 html2canvas 重建 DOM 可支持的样式。临时控件在快照前收起，等待布局、字体和关键图片就绪，再冻结一帧。视频、object-fit、滚动容器、阴影和跨域图像需要单独核对。html2canvas 的输入是 DOM。[html2canvas 文档](https://html2canvas.hertzen.com/documentation)
- **保留三个对象。** 底图只读；选区使用底图坐标；笔迹列表含工具、点集、样式、文字等参数。编辑层每次按顺序重放笔迹。橡皮对透明笔迹层使用 destination-out。底图、笔迹和区域合成决定最终输出。马赛克需要采样源像素，可先缩小后用最近邻放大，再将结果裁进涂鸦路径或圆角选框。
- **把一次动作算作一次撤销。** 笔按下时开始事务，抬起后提交；文字输入支持组合输入、确认、取消和继续编辑。参数跟随工具。放大查看和实际画笔宽度各有坐标系。历史按数量或内存限制，开始新编辑后清除相应重做分支。
- **输出。** PNG、复制和贴图共用同一次合成。贴图保存原始底图、标注和几何，以便二次编辑。选区落点对应虚拟屏幕中的原位置；滚动、缩放与透明度遵从原版。复制失败提供文件下载或体验内剪贴板等明确反馈。

## 长图与重叠

冻结选区，去除采集面板、固定工具栏等干扰，在真实虚拟内容滚动或手动换页后采样。将上一帧底部的若干行和新帧顶部的若干行取签名，搜索垂直重叠长度。先用降采样亮度或 RGB 筛候选位移，再对候选区域计算颜色误差。保留可信重叠时只追加新增行。

同一帧两次、重复条纹、滚动过快、固定页眉以及滚动途中动画应分别测试。置信度不足时给出可操作反馈；按产品设计允许显式追加下一页。单帧也能完成。点完成时处理最后一次防抖中或排队的采样。缩略图复用同一控件；限制总像素数，必要时分段存储，避免每次采样都在主线程复制整幅大图。

## 录制与导出

1. 在用户选好区域后创建固定输出尺寸的 Canvas。把虚拟场景裁到此画布，保留单调时间戳。用 canvas.captureStream() 得到媒体流，用 MediaRecorder 编码。录制范围由画布内容决定。真正共享显示器或麦克风属于另一种输入，需要相应用户操作与权限。[画布媒体流](https://w3c.github.io/mediacapture-fromelement/) [MediaStream Recording](https://www.w3.org/TR/mediastream-recording/)
2. 探测 API 与 MIME，MediaRecorder.isTypeSupported() 通过后仍要处理构造、start 和运行期错误。根据实际 MIME 设置扩展名。帧率参数给出采样目标；静止的画布可能只发出少量帧。录制过程中依据输出需要提交帧，别在每一帧重建整棵 DOM。CPU 紧张时量化采样成本，再决定缩小尺寸或降低帧率。
3. 同一录制会话维护“准备、录制、停止中、已就绪、失败”。重复点结束应幂等；等待最后的 dataavailable 和 stop 再组装 Blob。释放轨道、计时器、预览视频和对象 URL；页面隐藏、取消、重复录制、切换窗口都有明确定义。
4. 时间裁剪用两个独立可聚焦的端点；按实际帧率或媒体时间戳定义键盘步长。空间裁剪在解码像素坐标计算。真实截取所选时间范围时重新编码或用可用的媒体工具裁切。仅移动 video.currentTime 能预览区间。GIF 导出需要采样、量化调色板和逐帧延时，长任务支持进度与取消。
5. 解码最终文件，检查尺寸、能否播放、时长及两处不同时刻的内容。静音样例不要显示已录入系统声音。按范围公开时长、分辨率和浏览器编码限制。
