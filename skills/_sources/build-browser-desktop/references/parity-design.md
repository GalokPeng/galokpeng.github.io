# 功能对照与设计取舍

## 把“像原版”写成可以操作的条目

以一次用户意图作为一行，例如“修改文字后把截图贴回原位”。将安装版的页面、命令、快捷键和状态保存逻辑连起来。证据可来自源码、打开程序后的观察或产品方确认。以实际版本、路径或截图编号定位证据。截图只说明可见状态；要复现编辑器的撤销语义，还需对应实现或实际操作。

可复制下表到目标项目。示例中的行为用于演示如何写，实际以目标软件为准。

| 功能／原版依据 | 前置条件与输入 | 可观察的成功结果 | 取消、失败或重入 | 网页范围与验收 |
| --- | --- | --- | --- | --- |
| 打开应用／入口与窗口逻辑 | 窗口最小化，双击快捷方式 | 原窗口恢复，原文档仍在，焦点回到应用 | 连点任务栏时实例数保持正确 | 桌面内模拟；查实例数、草稿值、可见性 |
| 切换素材／图库及播放器 | A 已应用，预览 B，选 C | 桌面仍为 A，播放器显示 C | B 加载晚于 C 时丢弃 B | 真实媒体；人工延迟响应后检查资源 ID 与播放时间 |
| 标注后导出／编辑器渲染器 | 在矩形区域画两笔，只擦其中一笔的一段 | PNG 尺寸等于选区；擦除处露出底图 | 撤销一次恢复擦掉的部分，取消无输出 | 浏览器实算；解码 PNG 并采样有区分度的位置 |
| 操作系统设置／系统调用入口 | 点击改变真实系统设置的按钮 | 体验版说明作用域，或展示虚拟桌面内相应状态 | 退出体验后访客电脑设置如初 | 若需安装版，提供已有安装入口 |

状态可标为“待实现”“已实现待验收”“本地已验收”“线上已验收”“仅安装版”。一项可见按钮要有对应动作、结果和失败反馈。只有封面可用时标注“封面”，视频条目以实际播放验收。使用非默认初始方案展示产品特色时，在交付说明写明该选择。

## 为状态确定唯一归属

- **应用模型**持有文件、当前草稿、已应用值、历史和偏好。**窗口模型**持有实例身份、可见性、最小化前的几何、层级与焦点。窗口重绘不能触发“重新初始化所有设置”。
- **瞬态交互**存放指针 ID、拖动起点、选框、弹出菜单和未提交文字。按原版定义 Escape、右键、菜单外点击的含义。工具激活时优先处理其快捷键，再交给窗口，最后交给体验桌面。
- **外部媒体**区分条目 ID、预览资源、下载任务、已验证的原件、已应用的桌面实例。两张封面重名或列表重排时，用稳定 ID 恢复选择。将本次操作的 ID 与产生结果的任务绑定。
- **保存范围**按任务选。普通重绘用内存即可；同一标签页刷新可用带版本的 sessionStorage；需要离线保留大文件时评估 IndexedDB。对象 URL 的寿命属于创建它的文档，刷新后从 Blob 重新生成。

## 把原版的视觉系统带过来

先清点已获准使用的图标、光标、字体与媒体，以及它们的授权和署名。记录窗口标题栏、内容区间距、卡片列数、图标尺寸、字重、选中态、禁用态、菜单与锚点。用这些常量搭控件，在相同逻辑尺寸和主题下核对。比较不同平台的字体时优先检查换行、截断与对齐。

若访客需要下载，官网可用独立标题和下载区。把体验范围的说明放在显示器外层，交互菜单和软件文字放在内层。长英文、中文、窄屏和系统字体放大时重新排版。模拟桌面用合成的便签、路径和文件名，许可链接跟随具体媒体。

## 为目标功能选择执行位置

| 依赖 | 合适的执行位置 | 决策依据 |
| --- | --- | --- |
| 窗口、菜单、列表、轻量存储 | DOM、CSS、组件状态 | 需要文字输入、焦点、可访问名称和响应式布局 |
| 画笔、马赛克、裁剪、合成 | Canvas 2D；计算较重时考虑 Worker | 先量输入延迟、内存峰值、导出结果，再决定是否增加线程 |
| 可移植的排版、图像或音频算法 | JavaScript 或 WebAssembly | 已有可复用核心、有明确输入输出、依赖可移植、产物体积可接受 |
| 系统任务栏、全局光标、进程、开机启动 | 虚拟桌面内模拟或标为安装版专属 | 浏览器演示仅拥有自身页面。需要真实系统时，应另行设计有明确权限与退出恢复的运行环境 |

将业务逻辑、渲染和平台服务放在各自边界。这样同一个“应用主题”动作可以改变体验桌面的样式，也方便对照原版保存与恢复的时机。
