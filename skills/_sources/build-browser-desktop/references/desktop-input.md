# 桌面外壳与输入

## 宿主与桌面的边界

官网负责导航、语言、体验提示、下载锚点。模拟桌面作为单独路由，可直接打开，也可嵌入有可读 title 的 iframe。用 frame 内部的视口决定桌面布局；标题、窗口、便签、弹出菜单和任务栏都定位到桌面根元素。为窄屏提供合理高度或可最大化的应用，确保工具栏和退出入口可达。少量组件也可以在同一页面用独立根节点实现。

同源 iframe 便于共享静态素材，CSS 和焦点有各自的文档边界。同源脚本仍能访问彼此的文档。需要隔离不同信任级别内容时选用独立来源及适当的 sandbox / Permissions Policy。跨来源的宿主通信，用限定的 targetOrigin、event.origin、event.source 和已知消息结构。展示示例桌面只需要页面内输入，通常无需鼠标锁定、屏幕共享或读取系统剪贴板。

## 窗口模型与层级

| 动作 | 实现细节 |
| --- | --- |
| 从快捷方式或任务栏打开 | 用稳定的应用 ID 查找现有窗口；复用实例，按产品规则恢复、激活和聚焦。双击同时考虑 Enter 和触屏入口。 |
| 最小化、恢复、关闭 | 分开处理三个命令。把最小化前的矩形存起来。关闭时按原版处理草稿、录制、下载与对象 URL。将焦点移回可见入口。 |
| 激活窗口 | 在同一窗口层内更新前后顺序。桌面贴件、普通窗口、任务栏、临时菜单、截屏遮罩各有明确容器。注意 transform、opacity 和 isolation 会创建新的层叠上下文。 |
| 移动和调整大小 | pointerdown 记录初始矩形与指针，setPointerCapture 绑定该次手势；move 由初始矩形加位移求新矩形，up、cancel、lostpointercapture 都结束手势。只在拖动手柄或画布局部使用 touch-action。 |
| 最大化、还原和屏幕变窄 | 以虚拟桌面的边界重新约束窗口，让标题栏、完成和关闭保持可达；必要时内容区内部滚动。窗口的普通态矩形另存。 |
| 菜单与弹层 | 根据锚点、可用空间和实际菜单尺寸翻转或贴边，打开后设置焦点，关闭时归还。文字输入与 IME 组合期间保留编辑器的按键语义。 |

### 坐标只做一次换算

在 iframe 内接收的 clientX / clientY 与元素的 getBoundingClientRect() 已位于同一视口。拖动普通未缩放窗口时使用 CSS 像素。绘制、选区命中、橡皮和导出共享同一个“指针到内容像素”函数。以下公式用于无边框、无内边距、轴对齐且画面铺满整个元素的画布。

```js
function imagePoint(event, canvas) {
  const rect = canvas.getBoundingClientRect();
  return {
    x: (event.clientX - rect.left) * canvas.width / rect.width,
    y: (event.clientY - rect.top) * canvas.height / rect.height
  };
}
```

含有 contain 留白时先减去绘制区域的起点；cover 模式还要加回裁掉的源图偏移。若渲染器使用逻辑坐标并已设置 DPR 变换，就将事件映射到该逻辑尺寸。旋转或错切容器需要逆变换。用已知像素标记，在不同缩放、屏幕边缘和滚动后验证命中。对于窗口拖动，记录容器逻辑坐标；视觉缩放的外壳需同样换算位移。

## 原版指针和动效

1. 从可用的原版资源读取每种角色的图形、原尺寸、热点和帧时长。常见角色包括箭头、手形、I 字、十字、移动和四个缩放方向。动画光标可以拆成帧与元数据。
2. 以目标尺寸缩放位图并按同一比例调整热点，像素风可使用最近邻。CSS 写为 `cursor: url("arrow.png") 4 3, auto`，其中数字为该显示尺寸下的热点。资源准备好后再切换。在输入框、禁用项、调整区和画布之间，按当前操作决定角色。把样式限定在体验桌面。
3. 改色时保留 Alpha、描边和阴影。缓存键包含主题、角色、尺寸、颜色和帧。仅在指针停留且当前角色需要动画时计时，离开即停，进入官网外层后使用外层的指针样式。
4. 粒子作为不接收输入的独立图层。记录经过的距离与时间，限制每帧发射量，依据真实时间差计算惯性、重力和衰减。光晕跟随指针轮廓。指针静止后让旧粒子自然消失，页面不可见时停止绘制，尊重 reduced-motion 设置。

**验收动作。** 将窗口拖过桌面边缘再松手，移动指针检查窗口是否仍黏住；用 Tab 与 Enter 重开最小化窗口；在字号放大时打开最右侧菜单；在指针热点放一枚像素标记，验证点击、选区和笔尖落点重合。[Pointer Events 规范](https://www.w3.org/TR/pointerevents3/)
