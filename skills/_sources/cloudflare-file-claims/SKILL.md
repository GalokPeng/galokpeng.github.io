# Cloudflare 卡密文件领取

交付物是一个独立站点。管理员生成一次性卡密并复制带领取网址的说明。收件人兑换后逐个复制文件链接，在其他浏览器或下载工具中使用。每份卡密对每个文件默认有一次下载机会，管理员可以在发卡前后分别调整。

## 确定输入和范围

从用户给定的实际文件开始，确认要一起发放的文件集合。初始化器接受一个或多个非空文件，保留原文件名和字节，支持中文与空格。重名文件需要先确定对外文件名。站名、后台路径和默认次数可选。示例域名、管理路径及项目名都可以替换。仅要求本地制作或打包时，做到本地验收即可。

## 生成项目并验证

使用 Python 3.11+、Node.js 24 和 npm。从本 Skill 目录运行第一条命令，然后进入生成的项目。把命令中的示例文件换成用户的实际路径。

```sh
python scripts/init_portal.py --out ./download-portal --title "资料领取" --admin-path /manage --default-limit 1 "讲义.pdf" "练习素材.zip"
cd download-portal
npm ci
python portal.py local
npx wrangler dev --local --ip 127.0.0.1 --port 8787 --config wrangler.json
```

保持开发服务运行，从同项目的另一终端执行 `python verify.py`。本机领取页为 `http://127.0.0.1:8787/`，管理员入口使用配置的路径。本地凭据自动生成于 `.private/local.json`。验收会新建专用卡密、发起实际传输并核对内容，结束后按随机备注与卡密哈希清理该测试记录。详细检查见 [验收与故障定位](references/verification.md)。

## 部署到用户指定的域名

当用户授权上线时，按[部署与维护](references/deployment.md)检查现有账户、目标子域名及免费额度，依次执行 `provision`、`publish`、`verify.py --live`。后台路径可自定义，身份验证依赖独立口令。首次部署生成的生产密钥须留在对应项目中，向管理员交付口令时使用其指定的私密渠道。

## 验收后交付

给出领取网址、管理网址、口令的安全取用位置，以及实际通过的验证。区分本地与公网、浏览器模拟与真机测试。说明复制链接不计数，从头请求文件正文会占用该文件的一次额度；签名链接转发后共享同一余额。计数反映服务端开始发送。已有公开源链接可独立使用，限额只覆盖该站签发的下载地址。
