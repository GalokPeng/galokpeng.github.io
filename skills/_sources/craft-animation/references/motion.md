# 动作、材质与镜头

## 先找到应该改的那一层

遇到「很机械」，临时固定相机、关掉次级粒子，以纯色轮廓看一遍。若意图仍读不出来，沿时间轴标出准备、发力、接触和收势的位置，把时长优先留给观众必须辨认的动作。缓动只解决一段运动的速度变化。两个动作缺少因果时，补上触发事件，调缓动解决不了叙事的缺口。

保持同一时钟。渲染帧用 `t = frame / fps`，实时应用按实际经过的秒数取样。让位移、材质、相机震动和声音都读取同一个接触时刻。若模拟依赖历史，用固定步长推进并缓存状态，抽帧和倒回预览才能得到与整片相同的姿态。

## 运动与接触

| 画面 | 可执行的处理 | 检查位置 |
| --- | --- | --- |
| 转弯时全身像硬板 | 主体沿轨迹运动，让末端参考稍早的位置。按速度控制拖尾长度、按曲率控制侧弯，用同一变形驱动轮廓、法线和倒影。急停时衰减末端摆动。 | 顶点、反向前后一帧。低速时用上一次可靠方向或缩短拖尾，避免速度过零引起突然翻面。 |
| 鞋底、手指、齿轮在滑 | 在世界坐标固定接触点，求角色根节点及关节位置；滚动时使接触弧长和转角一致。镜头最后统一投影到屏幕。 | 同时叠绘接触点和物体局部标记；重心转移后再解除锁定。 |
| 碰撞看起来错开了一拍 | 找到两个表面首次相接的位置，用该点触发压缩、颗粒和声音。短促的硬撞击快起慢收；液体可先挤向侧面，再铺进介质。细粒的速度包含接触面的法向与切向分量。 | 看接触前后几帧的间隙、穿插、受压方向和结果位置。 |
| 字体或图表变化难读 | 保留字的基线、图表数值域及对象身份；同一对象沿连贯轨迹移动。转场中间留出能读的轮廓，读完再推进下一组。 | 缩小到目标版面，检查最挤时的标签、数值和停留时间。 |
| 角色显得没有意图 | 把视线落点、头部、躯干和末端的动作错开。跨步时先确立支撑脚，检查重心能否从这一支撑移到下一支撑。 | 看剪影、脚底与肩胯节奏，必要时暂时静止背景。 |

## 让物质在变化中保有身份

液滴可以从一个有厚度的截面开始。头部位置取当前轨迹，尾部参考数个更早的位置；活动速度越大，后半段伸展越多。让尾根有体积，末端逐渐变细，减速后由表面张力收回。第十二版水滴的取样窗口约为 35～160 毫秒，换速度、比例和镜头长度时要重新试。短拖尾可以直接变形同一表面；需要甩离的珠子才生成独立粒子。

白布、沙面、颜料等会留下痕迹的介质，需要两套量：当前接触压力，以及这个位置已经接收了多少痕迹。把接触点变换到介质局部坐标，在那里累积沉积量。布继续向镜头移动时，印迹就会跟着织物走。用材质纹理调节扩散速度，在高浓度的粗笔画里保留核心色，在边缘让纤维吃色。只有用户要求落成特定图形时才用原始轮廓约束扩散；分别检查图形的实体和留白。

## 镜头、空间与声音

长焦和正交视图都能压缩深度。需要表达物件从远处靠近时，安排稳定的消失点、连续的投影尺度和一两处能看懂的遮挡。布的朝向由法线决定，布的来向由质心轨迹决定，两者可独立控制。从侧面或顶视图看一次，可快速定位「突然翻面」「从地面冒出来」的原因。

声音用场景事件表驱动。若可听瞬态从音效文件第 120 毫秒才开始，文件起点应提前 120 毫秒以对准接触。多次碰撞可按材质、冲量大小调整音色和响度。更换声轨或改帧率后，在最终合成中重看同步。
